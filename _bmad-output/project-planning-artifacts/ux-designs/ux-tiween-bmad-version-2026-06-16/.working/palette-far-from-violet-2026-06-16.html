🎨 Tiween — Far From Violet

You crossed the wheel. These leave the cool/plum world entirely for the warm half — earths, rusts, olives — plus two wildcards. This is, not coincidentally, the palette of Tunisia itself: sand, harissa, zellige clay, olive, Sahara dusk. Action stays #F8EB06 yellow except where the field gets too warm to let yellow read — there I flex the action color and call it out. Each shows EventCard + chrome + error line. The teal chip = the Tiween-teal equity cameo (cool spark against warm fields = nice tension).
