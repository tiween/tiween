## Visual identity — LOCKED (from legacy spec, brand-book-derived)

- **Direction:** "Dark Cinema Aesthetic with Yellow Accent Strategy." Single dark theme (no light-mode toggle). Poster-forward, card-based, entertainment-app conventions.
- **Colors:** Tiween Green `#032523` (primary bg/surface), Tiween Yellow `#F8EB06` (accent/CTA/focus), White `#FFFFFF` (text), Surface Light `#0A3533`, Surface Lighter `#0F4542`. Semantic: destructive `#EF4444`, success `#22C55E`, warning `#F59E0B`, muted-foreground `#A0A0A0`.
- **Typography:** Lalezar (display, AR+Latin headlines) · Inter (Latin body/UI) · Noto Sans Arabic (AR body/UI) · JetBrains Mono (ticket IDs/technical). Min 16px base, 1.5 line-height.
- **Spacing/grid:** 4px base scale; mobile 4-col/16px, tablet 8-col/24px, desktop 12-col/24px max 1280px. Tailwind breakpoints. Touch targets 44px min / 48px preferred.
- **Elevation expressed via surface-color shift, not shadow.** Visual hierarchy L1 hero → L2 Lalezar section headers → L3 Inter card titles → L4 secondary text.
- **Components:** EventCard, ShowtimeButton, TicketQR, BottomNav (4 tabs), SeatSelector — anatomies specified in extract. Button hierarchy: Primary yellow (48px), Secondary outline (44px), Tertiary ghost (40px), Destructive red.
- **A11y:** WCAG 2.1 AA. Yellow-on-teal = 12.5:1, white-on-teal = 15.8:1. 3px yellow focus outline + 2px offset. Status = icon + text, never color alone.
- **i18n/RTL:** AR/FR/EN, Arabic-first then adapt to LTR. Logical properties, mirrored directional icons, instant flip on switch. Pricing in DT. FR-default UI copy.

## Design-improvement decisions (Ayoub approved — challenge invited)

Ayoub explicitly invited challenges to fonts/colors/layout. After reviewing the brand book + real mockups, three evolutions approved:

1. **Two-accent system (NEW — diverges from legacy + mockups).** Yellow `#F8EB06` was overloaded (CTA + active nav + recommended-star + links). Split:
   - **Yellow** = primary action + active/selected state ONLY.
   - **Cobalt blue** (brand secondary, from brand book) = links, info states, secondary highlights/tags.
   - Rationale: relieves a real signal-collision using an existing brand color; nothing invented.
2. **Lalezar reserved for brand moments (NEW — diverges from legacy "Lalezar all headlines").**
   - Lalezar → splash, hero, empty states, marketing, big brand numerals.
   - Routine in-app screen headers → cleaner heavy weight (Inter 700 / Cairo bold for AR) for scannability.
   - Rationale: heavy display face at UI sizes is shouty + hurts scanning when mixed with Inter body.
3. **Daylight treatment for outdoor-critical screens (NEW).**
   - App stays dark. **Ticket-QR screen and checkout get a light / high-brightness variant** for outdoor scanning (Tunisian daylight, cheap Android screens, 65% Chrome-Android audience).
   - Extends the legacy spec's "QR brightness-boost" hint into a fuller light pattern for those two surfaces.

**NOT changed (challenged but kept):** teal+yellow core palette (distinctive, AAA contrast, brand equity), taa-monogram logo, 2:3 poster-forward dark cards, conventional tab+carousel+bottom-nav layout (familiarity is a feature when displacing Facebook-page-checking; distinctiveness comes from content treatment — duotone cut-out portraits, monogram, Tunisian typography — not nav reinvention).

## Font challenge — second improvement round (2026-06-16, Ayoub approved)

Ayoub asked to challenge the font choices specifically. Role-by-role critique run against the brand book (geometric/rounded/warm wordmark DNA). Decisions:

- **Latin (body + headers): KEEP Inter.** Best small-size legibility on cheap Android/4G; free, variable. Brand voice carried by display/color/logo, not the workhorse.
- **Arabic body + headers: CHANGED Noto Sans Arabic → IBM Plex Sans Arabic.** Noto is the bland universal fallback; for an Arabic-first Tunisian product the AR face is the most brand-emotional typeface. Plex is geometric/warm/free, shares a humanist-geometric skeleton with Inter → AR+Latin on one line read as one system (reinforces the bidi rule). Also carries the AR header weight, so **Cairo's only remaining role is the Lalezar brand-moment fallback** for long AR copy.
- **Display: KEEP Lalezar for brand moments.** Already restrained; matches the Arabic wordmark energy; lowest churn.
- **Mono: KEEP JetBrains Mono** (no challenge — mono choice is immaterial for ticket IDs).
- Font chains: Latin `Inter` / `Lalezar → Inter` (display). Arabic `IBM Plex Sans Arabic` / `Lalezar → Cairo → IBM Plex Sans Arabic` (display).
- Applied to DESIGN.md (frontmatter + Typography table + chains), producer-prompt.md. EXPERIENCE.md unaffected (doesn't name the AR body font). Both spines remain `status: final`.
