# Overview

This document provides the complete epic and story breakdown for Tiween, decomposing the requirements from the PRD, UX Design, and Architecture into implementable stories.

## MVP Scope (Parity-First Relaunch)

The MVP focuses on **cinema showtimes discovery** only - matching legacy tiween.com functionality with a modern tech stack. Ticketing, watchlist, and B2B features are deferred to Phase 2.

### MVP Epics

| Epic                            | Status  | Scope                               |
| ------------------------------- | ------- | ----------------------------------- |
| Epic 1: Project Foundation      | **MVP** | Full                                |
| Epic 2A: Component Library      | **MVP** | Partial - discovery components only |
| Epic 2B: Strapi v5 Migration    | **MVP** | Partial - core content-types only   |
| Epic 3: Event Discovery         | **MVP** | Cinema showtimes focus              |
| Epic 4: User Authentication     | **MVP** | Basic auth only                     |
| Epic 5: Watchlist               | Phase 2 | Deferred                            |
| Epic 6: B2C Ticketing           | Phase 2 | Deferred                            |
| Epic 7: B2B Venue Management    | Phase 2 | Deferred                            |
| Epic 8: B2B Scanner             | Phase 2 | Deferred                            |
| Epic 9: Platform Administration | **MVP** | Partial - content management only   |
| Epic 10: PWA & Offline          | **MVP** | Partial - cached listings only      |

### MVP Value Proposition

**"Find what's playing at cinemas across Tunisia"**

Phase 2 adds ticketing, watchlist, and B2B features after validating the relaunch.
