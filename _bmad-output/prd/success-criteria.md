# Success Criteria

## MVP Success (Relaunch - Cinema Showtimes)

**Core Success Moment:**

- "I found what's playing at cinemas near me in seconds" - Discovery value

**MVP Measurable Outcomes:**

| Metric                 | Target   | Measurement                                    |
| ---------------------- | -------- | ---------------------------------------------- |
| Discovery Success Rate | >60%     | Sessions where user views film/showtime detail |
| Time to Discovery      | <2 min   | App open to relevant showtime found            |
| Return Visit Frequency | >3/month | App sessions per MAU                           |
| Showtime Lookups       | Track    | Engagement with core feature                   |

**MVP Launch Targets (30 days post-launch):**

| Metric        | Target   |
| ------------- | -------- |
| MAU           | 1,000+   |
| D7 Retention  | >20%     |
| Sessions/user | 3+/month |
| Critical bugs | 0        |

**Go/No-Go for Phase 2:**

| Signal              | Threshold               | Decision                  |
| ------------------- | ----------------------- | ------------------------- |
| MAU Growth          | Trending toward 5K      | Continue to Phase 2       |
| User Feedback       | Positive reception      | Product-market fit signal |
| Data Freshness      | Showtimes updated daily | Operations sustainable    |
| Technical Stability | <1% error rate          | Foundation solid          |

## Business Success

**Revenue Model (Phase 2+):**

1. **Ticketing Commission:** 8-10% standard, 5-7% for dashboard subscribers
2. **Credits System:** Users buy credits at 10-20% discount; margin built in
3. **B2B Subscriptions:** Venue dashboard access (pricing TBD)

**Phase Targets:**

| Phase        | Timeline    | MAU     | Revenue Target             |
| ------------ | ----------- | ------- | -------------------------- |
| MVP Relaunch | Month 1     | 1,000   | None (discovery only)      |
| Phase 2      | Months 3-6  | 5,000   | First transactions         |
| Growth       | Months 6-12 | 20,000  | 15,000 TND MRR             |
| Leadership   | Year 2      | 50,000+ | Operational sustainability |

**North Star Metric:**

- **MVP:** Weekly Showtime Lookups - sessions where user discovers what's playing
- **Phase 2+:** Weekly Cultural Discoveries - event views leading to meaningful action (watchlist, share, or purchase)
