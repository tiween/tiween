## 2. What Went Well

1. **Adversarial review caught a HIGH-severity defect before ship.** In 5.1, the offline pending-add queue used a single global localStorage key with an un-auth-gated drain — User A's queued add could replay into User B's watchlist on a shared browser. Fixed via a per-user namespaced, auth-gated, bounded queue.
2. **The pipeline learned within the epic.** `bad_spec` loopbacks concentrated in the first two stories (5.1, 5.2); 5.3–5.6 produced **zero** bad_spec — only hardening patches. Spec authoring quality rose sharply after the opening stories.
3. **Architecture-SOT discipline held.** The epic's "event vs. creative-work" ambiguity was resolved consistently by keying the watchlist on `creativeWork.documentId` (ratified schema) and reusing the existing `useWatchlist` react-query hooks — no rebuild, consistent 5.1→5.6.
4. **Pure-logic extraction made risk testable.** `deriveScheduleChange`, `collectWatchedCreativeWorkIds` were extracted and unit-tested, while boot-level lifecycle glue stayed deliberately thin.
5. **Offline-first infra compounded.** 5.1 built the per-user bounded queue → 5.2 extended it (remove/undo) → 5.4 read it offline → 5.5 synced it. Each story stood on the previous rather than re-inventing.

## 3. Challenges & Recurring Patterns

1. **Arabic-numeral bug recurred (5.4 and 5.5).** The `ar-u-nu-latn` fix appeared twice despite `project-context.md` mandating Western numerals. A known rule kept being missed.
2. **Cross-cutting debt punted story-to-story without closing:**
   - `startsWith` proxy allow-list matcher (no path-segment boundary) — flagged 5.1, still open.
   - Non-user-scoped react-query key `["watchlist","list"]` singleton — flagged 5.3, 5.4, 5.5.
   - `localStorage` not cleared on logout (shared-device leak) — 5.1, 5.4.
   - Non-atomic backend `add` dedupe (no unique `(user, creativeWork)` constraint) — flagged 5.5, pre-existing since 5.1.
3. **Documentation drift.** Epic context named email provider "Resend"; actual provider is **Brevo** (`@ayhid/strapi-provider-email-brevo`) — caught mid-5.6. `project-context.md` is also stale: Next.js 15.x (actual 16.1), Resend (actual Brevo), SWR/Zustand (Epic 5 used react-query).
4. **Binary/control-byte source file** in 5.6 hid from textual review for two passes until pass-2 caught it. Repo-hygiene gap.
5. **Integration-seam test gaps** — a recurring defer class: units tested in isolation but the wiring untested (EventDetailPage heart wiring, BottomNav badge mount sites). The mocked component suite structurally can't verify these.
