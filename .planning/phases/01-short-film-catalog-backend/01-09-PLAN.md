<objective>
Finish admin entry for short films in all three languages (SDATA-02): a publish bar with status and publish/unpublish for the current locale, the client-side D-19 pre-check from the same shared evaluator the server guard uses, translated mapping of the server's error codes, automatic slug generation, and locale tabs (D-22) where AR and EN edit only the localized fields.

This plan closes that gap without leaving the Works form for the native Content Manager, with the D-22 fallback if spike A3 refuted locale creation through the content-manager PUT.

Output: PublishBar, publishRules helpers, locale-aware hooks, LocaleTabs, LocalizedFieldsForm, jsdom and unit tests, and an operator guide `apps/strapi/docs/short-films-admin.md`.
</objective>
