<objective>
Per D-21, close the low-privilege path that let venue managers create, and instantly publish, short-film works through `POST /api/events-manager/venue/creative-works`. The server is the authority. The client venue form mirrors it so the option is not offered at all. Scheduling existing short films stays untouched.

Purpose: the venue create flow publishes immediately and cannot satisfy the D-19 short-film publish rules (poster, directing credit, watch source). Short films are admin-curated only (D-21). This work was split out of plan 01-06 because it is a separate subsystem (events-manager validation and the client venue form) and shares no file with the publish guard.

Output: `VENUE_CREATABLE_WORK_TYPES` on server and client, a server validation unit suite, a controller-level refusal test, and the client schema and form mirror.
</objective>
