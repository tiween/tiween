## Execution environment

- Yarn 1 only. Run commands from the repository root.
- Worktree runs have no node_modules (kernel): run `yarn install --frozen-lockfile` before any test, lint or build. If `apps/strapi/.env` is absent (fresh worktree), copy it from the primary checkout (locate it with `git worktree list`) or, failing that, from `apps/strapi/.env.example`. It is gitignored: never stage it, never paste its values into any file or SUMMARY.
- The working tree carries unrelated uncommitted user edits (`apps/client/package.json`, `.github/workflows/deploy.yml`, `.dockerignore`, `CLAUDE.md`, `_bmad-output/**`). Do not modify, revert, stage or commit them. Stage explicit paths only.
- Commits go to `main`, Conventional Commits (`test(01-01): ...`), no AI attribution trailers.
- Boot suites must run serially (`--runInBand`); they boot from `apps/strapi/dist/`, so any source edit requires `yarn workspace @tiween/admin build:test-dist` again (the stale-dist guard throws otherwise).
- Dist freshness is asserted, not assumed. `build:test-dist` stays `|| true`-tolerant because tsc exits non-zero on pre-existing type errors while still emitting, so every boot command in this plan first deletes the gitignored sentinel `apps/strapi/dist/src/index.js` and checks with `test -f` that the build re-emitted it (`--incremental false` re-emits every file) before jest runs. A build that emits nothing therefore fails the command instead of letting jest boot an old dist/. Second line of defence: `setupStrapi()` calls `assertTestDistFresh` (`tests/helpers/test-dist.ts`), which throws "dist/ has no compiled src/" when dist/ is empty and "dist/ is STALE" when any `src/` or `config/` source file is newer than every compiled file.
