> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary                                                                          | Description                                                                                                       | Data Crossing   |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------- |
| local secrets → test output / SUMMARY                                             | `apps/strapi/.env` holds APP_KEYS, JWT secrets, possibly ImageKit keys; test logs and SUMMARY files are committed | see description |
| npm registry → node_modules                                                       | `yarn install --frozen-lockfile` installs lockfile-pinned packages                                                | see description |
| repo `main` → production Postgres                                                 | `main` auto-deploys; Strapi syncs the schema at boot against live data                                            | see description |
| admin / importer input → stored JSON columns                                      | `country`/`language` are free-form JSON columns at the DB level                                                   | see description |
| anonymous internet → content API                                                  | `/api/creative-works/creative-works/short-films*` is unauthenticated (`auth: false`)                              | see description |
| creative-work rows → public JSON                                                  | rows carry drafts, internal relations, upload provider metadata and audit fields                                  | see description |
| admin / content-manager → Document Service                                        | any admin role that can publish creative works                                                                    | see description |
| seed scripts (tsx, operator machine) → Document Service                           | in-process caller, trusted operator                                                                               | see description |
| admin browser → Strapi upload API                                                 | file uploads go through Strapi's upload plugin and provider                                                       | see description |
| admin input → content-manager payload                                             | URLs and codes typed by an admin are stored and later rendered publicly                                           | see description |
| admin browser → content-manager API                                               | publish, unpublish, update and uid generation with admin auth                                                     | see description |
| data file (curated, committed) → importer                                         | operator-reviewed JSON drives writes                                                                              | see description |
| importer → remote image hosts                                                     | outbound HTTP fetches of thumbnails and posters                                                                   | see description |
| importer → upload provider                                                        | files land on ImageKit (or local disk)                                                                            | see description |
| third-party web sources → curated facts                                           | research reads external pages whose claims become public catalog data                                             | see description |
| data file → importer                                                              | the committed file drives writes and image downloads                                                              | see description |
| owner approval → import                                                           | only the owner's recorded decision unlocks `approved: true` in 01-13                                              | see description |
| operator machine → dev Postgres / ImageKit                                        | the CLI writes catalog data and uploads media with real credentials                                               | see description |
| venue manager (users-permissions) → POST /api/events-manager/venue/creative-works | low-privilege create-and-publish path                                                                             | see description |
| venue manager browser → client venue form                                         | untrusted client; the form is UX only                                                                             | see description |
