<objective>
Close the two remaining Phase 1 admin-authoring gaps on the Works form. Then run the final end-to-end verification for the whole gap-closure set.

- **G-01-2 (major, review WR-03).**
  - **Problem.** `streamingLinks` and `featuredRank` stay in the form state and in `workFormSchema` for every work type, but their sections render only for short films. A blank streaming-link URL left behind after switching to Film fails the Zod resolver on a field that is no longer on screen. The form is `noValidate`, so Save sends nothing and shows nothing. Even on a short film, the URL input only turns red, because the `INVALID_HTTPS_URL` code is never translated.
  - **Fix.** Follow 01-EXPERIENCE.md ("Short-film-only fields … are not validated, and not sent, when the type is not Short film"):
    - Validate streaming links and featured rank only when the type is `short-film`, through a `superRefine`.
    - In the same `superRefine`, validate `theatreDetails` (its bounded `actCount`) only when the type is `play`. Its section is play-only and the payload already sends `null` for other types, so it is the same hidden-field class.
    - Omit `streamingLinks`, `featured` and `featuredRank` from the payload for other types.
    - Show a translated `Field.Error` under the URL input, and a danger notification on any invalid submit.
  - **Why omit instead of strip.** Omitting the keys, rather than sending `[]`, keeps the 01-08 decision intact: stored components are never stripped on a type switch, because an update that omits a key leaves the stored value as it is. A boot case pins this.
- **AR RTL (owner-added).** The Arabic tab of the Works form sets no `dir`, so Arabic titles and synopses are typed left-to-right. `apps/strapi/DESIGN.md` § Inputs / Fields requires `dir="rtl"` on Arabic content inputs, and `dir="auto"` for mixed content.

Purpose: SC1 / SDATA-02 holds without operator traps. Every Save gives feedback, and Arabic is edited as a first-class language (apps/strapi/PRODUCT.md principle 3).

Output: the type-conditional schema and payload, the visible translated errors, RTL on the Arabic tab, a flipped walkthrough with new assertions, and a full green verification pass (boot, unit, jsdom, lint, type-check, Playwright).
</objective>
