# Phase 2 — UI Design Contract

> Visual and interaction contract for the Strapi-backed short-film pages: the detail page (`/[locale]/shorts/[slug]`), the `ShortFilmCard` heart, the `/[locale]/shorts` directory (grid, errors, Load more, empty catalogue) and the short-film entry on the watchlist page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **One design system.** Everything here is the public site (Tiween DS, `apps/client/DESIGN.md`). No Strapi admin UI is touched in this phase (no `apps/strapi` change; the API is the Phase 1 contract).
>
> **Upstream, not re-asked:** `02-CONTEXT.md` D-01 to D-16 (locked), `apps/client/DESIGN.md`, `apps/client/PRODUCT.md`, `04-DESIGN.md` / `04-EXPERIENCE.md` (adjacent phase; this spec is built to migrate into it with no rework), `05.1-UI-SPEC.md` (format, tone, state vocabulary). Anything not traceable to those is marked **[default]** (researcher choice, owner confirms at the mockup gate). Items only the owner can settle are collected under **Open questions for owner**.

## Part A — Short-film detail page (`/[locale]/shorts/[slug]`)

**Focal point:** the hero (film title over the backdrop) with the single gold "Regarder le film" pill directly beneath it; everything added in this phase (origin lines, crew grid, sub-labels, heart) stays secondary to that pair.

Order of sections (top to bottom, 920px column, 16px gutter): hero, action row, synopsis, distinctions, where to watch, **Équipe artistique (new)**, Distribution (cast), Dans la même veine, fixed sticky bar. Sections with no data are omitted entirely, never rendered as an empty heading.

### A1. Hero text stack (SPAGE-04, D-11)

Bottom of the hero, in this order:

1. Chip row (unchanged).
2. `<h1>` title (Lalezar, unchanged). When the served locale differs from the page locale it is wrapped as `<bdi lang="fr">` (see A6).
3. **Original-title line (new).** Shown only when `originalTitle` is non-empty and differs from the displayed title (case- and diacritic-insensitive). Meta 14/400, `#B0A6B8`, 4px under the title: "Titre original : {title}". The title is in `<bdi dir="auto">`; set `lang="ar"` when the string is Arabic script (`isArabic`), otherwise set no `lang` (the API does not return the original language code).
4. Meta line (unchanged): directors · year · duration · genres.
5. **Origin line (new).** Meta 14/400, `#B0A6B8`, 4px under the meta line: `{countries} · {languages}`. Names come from `Intl.DisplayNames` in the **page locale** (regions for `country`, languages for `language`), joined inside each group with `Intl.ListFormat(locale, { type: "unit", style: "narrow" })`, groups joined by " · ". Each group is preceded by a visually hidden label ("Pays" / "Langue", plural-aware) so assistive tech reads "Pays : Tunisie, France · Langue : arabe tunisien". An empty group is omitted with its separator; if both are empty the line is not rendered. Never print a raw code.
   - `aeb` (Tunisian Arabic) is the one code the launch catalogue is likely to need and may lack a CLDR name in the runtime ICU. Add a three-locale override (`shorts.languageNames.aeb`: "arabe tunisien" / "العربية التونسية" / "Tunisian Arabic") consulted before `Intl.DisplayNames`; if `DisplayNames` returns the code unchanged and no override exists, drop that entry.
6. On narrow widths the origin line wraps; it never truncates. The hero scrim already covers this area; if a real backdrop pushes the muted text below 4.5:1, the scrim stop (not the text color) is darkened.

### A2. Équipe artistique — crew grid (SPAGE-03, D-09, D-10, D-12)

- Section: `<section>` with `<h2>` "Équipe artistique" (Title 18/700), placed **before** Distribution (people sections stay together). Omitted when there is no non-cast credit.
- Content: every non-cast credit, grouped by `creditRole.department` in this fixed order: directing, writing, production, camera, editing, sound, music, art, costume-makeup, lighting, stage, other. Within a group, sorted by `billing` ascending (nulls last, then API order). Directors also stay in the hero meta line. One row per credit (the same person with two roles in one department gets two rows; no merging) **[default]**.
- Group: `<h3>` department heading (Label 14/700, `#B0A6B8`, 8px above its list), then a `<ul role="list">`. Groups 24px apart.
- Row (not interactive; people have no page): flex, 8px gap between disc and text, `min-height` 48px, 8px between rows. Left to right in LTR / mirrored in RTL: **initials disc** (40px) then text block: name (Body 16/700, up to two lines then ellipsis, `<bdi>`) over role (Meta 14/400 `#B0A6B8`, one line, `<bdi>`).
- Layout: one column under 480px of container width (the detail page's existing `sfd-content` container query, `30rem`); two columns from 30rem with a 16px column gap, filled in reading order row by row.
- Role label: `creditRole.slug` resolved from `shorts.crew.roles.<slug>`; an editor `customRole` wins when set; an unknown slug falls back to a humanized slug ("sound-mixer" becomes "Sound mixer"), never blank (D-09). Department headings from `shorts.crew.departments.<department>`; an unknown department falls under "other".
- **Initials disc** (shadcn `Avatar` + `AvatarFallback`, `aria-hidden`, the name sits beside it): Surface Raised `#3E2A48` fill, 1px Border `#4A3556`, initials in Foreground (Label 14/700). Initials rule: first letter of the first and the last word of the name, uppercased, at most two; a one-word name gives one letter; computed on grapheme clusters (`Intl.Segmenter`), never on UTF-16 units. Arabic-script names get U+200C (zero-width non-joiner) between the two letters so they do not join into one glyph. No gold, no category hue, no photo.
- Cast rail ("Distribution") uses the same disc at 88px (initials Title 18/700) in place of the shipped empty stripe avatar. The photo branch is removed (the API exposes none). Cast name and role styles are inherited.

### A3. Where to watch — access-type sub-label (SPAGE-03)

- Under each platform name in `.streamingInfo`, a sub-label: Meta 14/400, `#B0A6B8`, 4px under the name (no icon; it is plain text, not a status color). Content: the translated access type (`shorts.access.<free|included|subscription|rental>`), then, when the link carries an editor `label`, " · " and that label verbatim in `<bdi>` (editor-supplied, not translated).
- A missing or unknown `accessType` renders no sub-label (the row still shows).
- Platform names are brand names, never translated: YouTube, Vimeo, Dailymotion, Artify, ARTE, MUBI, Netflix, Shahid, TV5MONDE (the full 10-value enum; `other` and any unmapped value use `shorts.otherPlatform`). The shipped `PLATFORM_NAMES` map covers five of the nine named platforms and must be extended.
- The "Regarder" outlined pill (44px) and the stripe logo tile are unchanged.

### A4. Watchlist heart (FR19, FR20, D-14, D-15)

The shipped 52px round heart in the action row (border 1.5px `#4A3556`, `#31203A` fill, 22px glyph) keeps its geometry and becomes real. States and behavior are the shared state machine in **Part E**; detail-specific rules:

- Unsaved: outline glyph, `#B0A6B8`. Saved: filled glyph in Gold Leaf and the border steps to Gold Leaf (shape change plus fill, never color alone). Stacked glyph crossfade with no layout shift (shipped).
- Label per state with the film title omitted ("Ajouter à ma watchlist" / "Retirer de ma watchlist"); `aria-pressed` reflects the state.
- Unresolved check on a signed-in visit: the glyph is replaced by a 16px spinner after 200ms, `aria-busy="true"`, taps ignored.
- The sticky bar and the related tiles carry no heart.

### A5. Detail error and not-found (SPAGE-05, D-07)

Both render inside a full-height Midnight Aubergine field with the app header (the detail page's own header is only present on a successful render), content centered, max 420px, 48px vertical padding, using shadcn `Empty`.

- **Failure** (`app/[locale]/shorts/[slug]/error.tsx`): 48px `AlertCircle` in `#FF8A8A` plus text (never the icon alone), headline (Title 18/700) "Ce court métrage ne se charge pas", body (Body 16/400, `#C9C0D0`) = `t('errors.<CODE>')`, primary gold pill "Réessayer" (48px, `RotateCw` icon), then a tertiary link "Voir tous les courts métrages" (Gold Tint text, 44px). `role="alert"`. Retry runs `router.refresh()` inside `startTransition`, then `reset()`; while it runs the button is `aria-busy` with a spinner after 200ms; if it fails again focus stays on the button.
- **Not found** (`SHORT_FILM_NOT_FOUND`, the only code that maps to `notFound()`; segment `not-found.tsx`; HTTP 404): 48px `Film` icon in `#B0A6B8`, headline "Court métrage introuvable", body `t('errors.SHORT_FILM_NOT_FOUND')`, primary gold pill "Voir tous les courts métrages". Not an alert.
- Never show an outage as a 404 or the reverse. Never show a stack trace, a status number or an error code.
- **Caching constraint (D-05 with D-07):** the failure UI must come from a thrown error and `error.tsx`, never from a page that renders successfully with an error shell, otherwise the 60-second ISR window caches the outage for every visitor.

### A6. Silent French fallback (FR56, D-11)

No visible label, ever. When `item.locale` differs from the page locale, the nodes that carry the fallback text get `lang="fr"` (title `<bdi>`, synopsis `<p>`, each distinction/credit string the API overlaid) and, when the page is Arabic, also `dir="ltr"` with `text-align: start`. The page chrome stays in the page locale. Text is never blank: a title is always present, a missing synopsis simply omits the section. The `lang` tag applies per node, so a page with an Arabic title and a French synopsis tags only the synopsis.

### A7. Detail loading

`app/[locale]/shorts/[slug]/loading.tsx`: a hero-height Surface block (clamp 440 to 580px) with the reserved stripe, three `Skeleton` bars for the title block and a 52px round block for the heart; `aria-busy="true"` with visually hidden "Chargement du court métrage". Static under reduced motion; no spinner before 200ms.

## Part B — `ShortFilmCard`

### B1. Heart (FR19, D-13)

- A `WatchlistButton` rendered as a **sibling of the card `<Link>`**, absolutely positioned `end-1 top-1` (4px inset, logical), `z-20` (link is `z-10`, so it is an independent target exactly like the trailer button). Never nested inside the link.
- Geometry: 44 x 44 target, `rounded-full`, transparent; inside it a centered 40px disc and a 20px glyph.
- Disc, unsaved: Aubergine Deep at 80% with a 12px backdrop blur, 1px Border `#4A3556`, outline heart in Foreground. Disc, saved: same scrim and border, heart **filled Gold Leaf**. Saved vs unsaved differs by shape (filled vs outline) and by `aria-pressed`, not by color alone. No shadow.
- Always visible at every breakpoint and input (it does not wait for hover; the desktop hover overlay at `z-5` sits under it).
- Hover (fine pointer): disc to Aubergine Deep 92%. Press: scale 0.95. Focus: the global 3px Gold Leaf ring (offset 2px) on the 44px target. Pulse on save: the existing 300ms `animate-watchlist-pulse`, collapsed under reduced motion.
- The click handler stops propagation and prevents default (the trailer-button pattern), so a heart tap never navigates.
- Accessible name includes the film: "Ajouter « {title} » à ma watchlist" / "Retirer « {title} » de ma watchlist" (24 identical hearts on a page must be distinguishable in a screen-reader control list).
- Saved-state source: one watchlist-list query for the whole grid (or one batch check), **not** one `check` request per card. A signed-in grid must resolve all hearts together without a per-card spinner flash; while unresolved the heart shows the unsaved outline with `aria-busy="true"` and ignores taps (no spinner on cards).
- Skeleton and `isLoading` cards render no heart.

### B2. Duration relocation (D-13) — proposal for the mockup to confirm

The top-end corner is now the heart's, so the duration pill (`bg-black/60`, white text, clock icon) is **removed**. Duration joins the card's meta in the bottom scrim:

- Line 1: director (truncates, `<bdi>`).
- **Line 2 (new, replaces the "• year" suffix): `{year} · {duration}`**, e.g. "2025 · 14 min", `<bdi>` per run, `·` separator, each part omitted when absent (no lone separator, no "0"). Same text size and color as today's byline (the card's shipped small text, `white/70` today, `#B0A6B8` target).
- Applied identically to the mobile bottom overlay and the desktop hover overlay (one shared fragment).
- The scrim grows by one line; the existing `pt-12` stays. The 2:3 frame never changes size.
- The link's screen-reader text keeps title, director, year and duration.
- Why this spot: it is exactly where `04-DESIGN.md` puts duration ("moves from the top-end pill into the meta line"), so Phase 4 only prepends the genre to line 2. Rejected: the top-start stack under the featured badge (competes with the badge, and a duration chip would be a third overlay on a 171px poster); a corner-badge swap (heart must own the top-end corner).

### B3. Silent fallback on cards

If the served locale differs from the page locale, the title `<bdi>` carries `lang="fr"` (and `dir="ltr"` on an Arabic page). The poster `alt` stays empty (the link names the film).

### B4. Unchanged in this phase

Featured badge, category handling, hover overlay, trailer button, grain and `rounded-2xl` frame. The black scrims, the grain and the desktop hover overlay are Phase 4's removals; do not touch them here beyond the two changes above.

## Part G — Accessibility and RTL

- WCAG 2.1 AA; **axe-core clean at 390px in fr, ar and en** for: directory (results, empty catalogue, error), detail (full data, sparse data, error, not found), watchlist with a short-film entry. jsdom cannot compute contrast; record a manual contrast pass (the figures in Color).
- Landmarks and headings: one `<h1>` per page (directory "Courts métrages", detail = the film title); detail sections `<h2>`; crew departments `<h3>`; cards stay `<article>` with an `<h3>` title; the grid sits under the sr-only `<h2>`.
- Each card has exactly **two** controls in DOM order: the whole-card link, then the heart (then the desktop trailer button, unchanged). The heart is never inside the link.
- Targets 44px minimum with 8px between them (heart, Load more, retry, "Voir tous les courts métrages", suggestion trigger). The detail heart is 52px.
- Focus: global 3px Gold Leaf ring, 2px offset; dark ring on gold-filled pills. Logical tab order equals visual order in both directions.
- Live regions: result line `role="status"` polite; load-more loading `role="status"`; errors `role="alert"` (directory error block, detail error block, inline load-more error); toasts are the shipped polite region. Empty-catalogue and not-found are plain content, not alerts.
- Status is never color alone: saved vs unsaved = filled vs outline plus `aria-pressed`; every error icon sits beside text; the access type is text.
- `prefers-reduced-motion`: instant scroll and focus moves, no pulse, no card lift, static skeletons.
- 200% zoom and 320px width: no horizontal page scroll (the cast and related rails scroll inside themselves and stay focusable).
- **RTL (Arabic):** `dir="rtl"`; logical properties only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `inset-inline-*`); the heart is at the **top-left** of the poster in Arabic (top-end), the featured badge top-right; the crew grid fills right to left with the disc at the right of its text; the directory grid's first card is top-right; `ChevronRight`-type icons mirror, `Heart`, `RotateCw`, `AlertCircle`, `Film` do not; digits Western; every title, director, country, language, platform name and editor label is `<bdi>`/`dir="auto"`; a fallback French block inside an Arabic page is `dir="ltr"` with `lang="fr"`. ## Open questions for owner

None of these blocks the pipeline; each has a stated default the planner can build against.

1. **Watchlist heading (D-16 stands; owner note only).** Short films sit in the one list, in the "À venir" section after dated events, so that heading is slightly off for an undated short film. This does not change D-16. If it bothers you at the mockup gate, the alternative is a separate "À voir" section for short films (needs a third partition and a new key); it is not specified here.
2. **Meaning of `accessType: included`.** The enum is free / included / subscription / rental. Default label "Inclus" is a placeholder. Say what "included" means for a visitor (included in a plan they may already have? bundled with another work?) and the label becomes exact in FR, AR and EN.
3. **Render the streaming `label` (e.g. "VOST")?** Default: yes, appended after the access type as editor-supplied text, untranslated. It is free text in whichever language the editor typed; say if it should be hidden or become a controlled value.
4. **Heart disc style.** Default: dark scrim disc with a filled Gold Leaf glyph (matches the detail heart and DESIGN.md "fills gold when saved"). Alternative: a full Gold Leaf disc with a Gold Ink heart (louder on busy posters, but a gold fill on every saved card).
5. **Duration/year placement on the card.** Default: a second meta line "2025 · 14 min" under the director (the Phase 4 spot). The mockup confirms; the alternative on the table was the top-start stack.
6. **Return after sign-in.** Default: the visitor returns to the page and taps the heart again. Alternative: remember the intent and save automatically after sign-in (more work, and an action the visitor did not repeat).
7. **Terminology.** Default: "watchlist" everywhere (matches the shipped page title and Arabic "قائمة المتابعة"), replacing the shorts-only "Ma liste". Say if the product should instead say "Ma liste" site-wide.
8. **Arabic review.** The Arabic role, department, access-type and error strings are drafts (same status as Phase 4). The owner reviews them before launch (Phase 6 carries the AI-drafted Arabic review).
9. **Watchlist page copy that still says "événements"** (subtitle, empty state, "Aucun événement dans cette catégorie"): deferred to Phase 6 so the shorts feature is not advertised while unlinked. Confirm, or pull a neutral rewrite into this phase.
