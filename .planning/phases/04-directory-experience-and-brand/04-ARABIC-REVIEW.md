### Needs a code change (cannot be fixed in the JSON alone)

- **Minutes agreement.** `shorts.minutes` (دقيقة) is placed after a bare number in `ShortFilmDetail` and `ShortsHero`, and `availableDuration` (`متاح — {duration} دقيقة`) is fed a string. Arabic needs «دقائق» for 3 to 10 and «دقيقتان» for 2. Many short films run 3 to 10 minutes, so «5 دقيقة» will show on real cards. Fix: turn these, and `filters.durationRange`, into ICU plurals on a **numeric** argument (selection only), keep digits in a bare `{display}`/`{duration}`, and update the call sites, which currently pass `String(...)`. The fallback is the abbreviation «د», but that is less clear to readers.

**Imperatives:** visitor actions and error instructions use the masculine-singular imperative (شاهد, اقترح, امسح, أزل, طبّق, أدخل, أعد المحاولة). Neutral system controls keep the verbal noun (رجوع, مشاركة, تشغيل, إغلاق, عرض المزيد). That is a common Arabic UI convention and was not changed. Gender-inclusive phrasing (masculine generic) is a decision for the owner.
