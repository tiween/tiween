## Sampling Rate

- **After every task commit:** Run the task's single-file command
- **After every plan wave:** Run the full Strapi suite + lint; after server waves also `test:integration`; after client waves the client full suite + lint + type-check
- **Before `/gsd-verify-work`:** Full suites, both lints and `test:integration` green with output captured; manual axe + RTL + keyboard pass recorded in FR/AR/EN
- **Max feedback latency:** 120 seconds
- **Kernel rule:** a task whose boot command could not execute is `blocked`, never `done`
