# Phase 05.1 — UI Design Contract

> Visual and interaction contract for the festival programme page (`/[locale]/festivals/[slug]`), the film detail page (`/[locale]/films/[slug]`) and the Event-groups admin page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Two design systems, never mixed.** Parts A to F and H cover the **public site** (Tiween DS, `apps/client/DESIGN.md`). Part G covers the **Strapi admin** (Strapi Design System v2, `.claude/skills/strapi-design-system/`). Strapi DS tokens, indigo `#4945FF` and 4px radii never appear on the public site; Gold Leaf, Lalezar and pill buttons never appear in the admin.
>
> **Upstream, not re-asked:** `05.1-DESIGN-BRIEF.md` (locked, D-00), `05.1-CONTEXT.md` D-01 to D-21, `apps/client/DESIGN.md`, `apps/client/PRODUCT.md`, `05.1-RESEARCH.md` (payload shape, time helpers, reuse reality check). Anything below that is not traceable to those is marked **[default]** (researcher choice, owner confirms at the mockup gate).

## Spacing Scale

Public site (4px base, from DESIGN.md; multiples of 4 only):

| Token | Value | Usage                                                                               |
| ----- | ----- | ----------------------------------------------------------------------------------- |
| xs    | 4px   | Icon-to-text gap, chip vertical padding                                             |
| sm    | 8px   | Gap between targets (minimum), gap between chips, list-row inner gap                |
| md    | 16px  | Card padding, page gutter on mobile (4 columns, 16px margins), gap between cards    |
| lg    | 24px  | Section padding, gap between day groups, gutter at 640px and up                     |
| xl    | 32px  | Gap between venue sections, film page section spacing                               |
| 2xl   | 48px  | Major breaks (festival header to switcher on desktop, film page rail spacing)       |
| 3xl   | 64px  | Page bottom clearance base (plus bottom-nav 64px and `env(safe-area-inset-bottom)`) |

Layout widths: mobile under 640px = 4 columns; 640 to 1023px = 8 columns, 24px gutters; 1024px and up = 12 columns, container max 1280px; film detail reading column 920px, long text capped at 660px; By-date programme list capped at 720px.

Exceptions (all multiples of 4):

- Touch targets: 44px minimum height and width (day tile, view tab, chip, venue combobox, icon button, film row); 48px for the primary button. Targets keep at least 8px between them.
- Poster thumbs in the programme card: 40 x 60 (supporting films) and 56 x 84 (the feature); By-film row poster 64 x 96 (mobile) and 80 x 120 (from 640px).
- Day tile: 56px wide (grows to fit the 14px weekday text), 64px tall.
- Sticky stack (view switch 48px + day strip 64px) = 112px plus the app header.

Admin (Strapi DS): its own 4px grid in DS spacing steps; page gutters and card padding follow `pages/Works` (`Layouts.Content`). No custom pixel values.

## Typography

Public site only (this count does not apply to the admin, which uses Strapi DS roles, see below). Honest count **including every exception: four font sizes (14, 16, 24, and the fluid Display) and two weights (400 and 700)**. Nothing else is declared anywhere in this spec. Reconciled with DESIGN.md: its 11px label, 15px Body Long, 18px Title and 600 label weight are intentionally not used, so the contract holds to four sizes and two weights.

| Role                                | Size                                      | Weight                                                       | Line Height                       |
| ----------------------------------- | ----------------------------------------- | ------------------------------------------------------------ | --------------------------------- |
| Body                                | 16px                                      | 400 (700 for film titles, times, venue names, button labels) | 1.5 (24px); 1.65 for the synopsis |
| Meta                                | 14px                                      | 400                                                          | 1.43 (20px)                       |
| Label                               | 14px                                      | 700                                                          | 1.43 (20px)                       |
| Heading                             | 24px                                      | 700                                                          | 1.33 (32px)                       |
| Display (film-page hero title only) | `clamp(44px, 8vw, 72px)` (one fluid size) | 400 (Lalezar is a single-weight face)                        | 0.98                              |

Used for:

- **Display (Lalezar 400):** the work title in the `/films/[slug]` hero only. This is a hero, which the DESIGN.md Brand Moment Rule allows ("Lalezar appears only on heroes, splash, empty states and marketing"); it never appears on the festival page or on routine headers. Long Arabic titles use Cairo 700 per DESIGN.md (the same Display size; the 700 weight is the second declared weight).
- **Heading 24/32 (Inter / IBM Plex Sans Arabic 700):** festival name, film-page section titles, empty-state headings.
- **Body 16/24:** film titles (700), programme time (700), venue name (700), button labels (700). **The synopsis is Body at 16px, 400, line-height 1.65, capped at a 660px measure** (no separate 15px size).
- **Meta 14/20 (400):** director, runtime, total runtime, address, language line, original-title line, programme summary line, order numeral, cast names and roles; day-group sub-headings use the Label role (700).
- **Label 14/20 (700):** chips, status labels, section label text, "Équipe du film présente", weekday on the day tile, "Auj.", the "Long métrage" tag.
- Every foreign-script run inside a line (an Arabic title next to a venue, `VOST`, `15:00`) is wrapped in `<bdi>` or `dir="auto"`. Digits are Western in all three locales.

Admin (separate system, not counted in the public four sizes / two weights above): Strapi DS typography roles only (`alpha` page title, `beta` section header, `omega` body, `pi` table header, `sigma` overline), Strapi DS weights 400/500/600, 14px body.

## Part A — Festival page (`/[locale]/festivals/[slug]`)

### A1. Structure (mobile, 390px)

Top to bottom, 16px side gutters:

1. **App header** (existing, sticky). Bottom nav 64px fixed; page bottom padding = 64 + 64 safe area + `env(safe-area-inset-bottom)`.
2. **Festival header** (not sticky, compact, about 96px): 64 x 96 poster (12px radius, stripe artwork if missing) at inline-start; at inline-end of it, the festival name (Heading 24, `<h1>`), then Meta line "{start} – {end} · {n} lieux" (#B0A6B8); share icon button (44 x 44, `Share2`, label "Partager le programme") at the far inline-end, opening `ShareDialog`.
3. **Before/after banner** (only outside the festival dates): `alert` on Surface with an info icon + text, Meta 14. See copy.
4. **Sticky stack** (112px): `ViewSwitch` (48px, three equal tabs) then `DayStrip` (64px). Translucent Aubergine, 12px blur, hairline below.
5. **Filter row** (scrolls away, 52px): venue combobox button (44px, `MapPin`, label "Tous les lieux" / selected venue) then section chips, all in one `overflow-x-auto` row with scroll-snap; By-film replaces it with the search `Input` (44px).
6. **View content**.
7. **Footer block:** `TmdbAttribution` (see Part C) because film posters and data come from TMDB.

### A2. Desktop (1024px and up)

Two columns inside the 1280px container, 24px gutters:

- **Sticky sidebar, 240px, `top` = header height + 16px:** festival poster 96 x 144 + name + dates + share; the view switch as a **vertical** tablist (3px inline-start gold rule on the selected item); venue combobox; section chips as a wrapping list; By-film search input.
- **Main column:** `DayStrip` (sticky under the app header, 64px) then the view content.
- By date: one column, max 720px. By venue: venue sections **side by side**, 2 columns from 1024px, 3 from 1280px, 24px gap. By film: single column of rows max 720px, screenings wrap inline.
- Between 640 and 1023px: mobile structure with 24px gutters and wider tiles; the By-venue view uses 2 columns.

### A3. View switch

- shadcn `Tabs` (`@/components/ui/tabs`), three tabs, equal width, 48px tall, label Body 700 (selected) / 400 (others), `aria-controls` panel. Arrow keys follow reading direction (RTL swaps Left/Right). Home/End supported.
- Selected: white label, 2px Gold Leaf rule at the bottom (no fill). Resting: `#B0A6B8`. Hover: `#FFFFFF`. Pressed: Surface Raised wash.
- Changing view updates `?view=date|venue|film`. View and day changes use `router.push` so Back steps through them; filter, search and `programme`/`film` anchors use `router.replace` **[default]**.

### A4. Day strip

- A shadcn `ToggleGroup` (`type="single"`, `aria-label` "Jours du festival") of day tiles inside a horizontal shadcn `ScrollArea`, `scroll-snap-type: x mandatory`, `scroll-snap-align: center`, hidden scrollbar, 8px gap, 16px inline padding. The active tile is scrolled into view with `scrollIntoView({ inline: "center", block: "nearest" })` (instant when `prefers-reduced-motion`).
- Tile: button, 56 x 64 minimum (grows to fit longer weekday names, never below 44 x 44 hit area), Surface fill, 8px radius, no shadow. Content stacked and centered: weekday short name (Label 14/700), day number (Body 16/700), and the short month name (Label 14/700) only when the strip crosses a month boundary; otherwise omitted.
- The tile for the current festival day (D-11 05:00 cutoff) shows "Auj." / "اليوم" / "Today" in the weekday slot, so today is identified by text.
- Selected: Gold Leaf fill, Gold Ink text, 2px Gold Ink underline bar (non-color cue), `aria-pressed="true"`.
- A day with no programmes keeps its tile (the strip never reorders) with Muted text and an `aria-label` that ends with "aucune séance"; it is still selectable and shows the empty-day state.
- Programmes after midnight belong to the previous tile (D-11).
- Keyboard: each tile is a normal tab stop (at most about 10); `Enter`/`Space` selects. Arrow keys also move between tiles (roving, RTL-aware). Strip content order mirrors in Arabic (first day at the inline-start, which is the right edge).
- **By film:** the strip is optional. Its first tile is "Tous" ("Tous les jours") and is selected by default; selecting a day restricts every film's screenings to that day and hides films with none. URL `day` is absent when "Tous" is selected. **[default]** The By-film view otherwise has no day-based scroll position.

### A5. Filters

- **Venue combobox** (By date, By venue): shadcn `Combobox`, searchable single-select, trigger 44px with `MapPin` icon and the selected venue name (truncated, `bdi`). First option "Tous les lieux". Items 44px tall. Closes on select; focus returns to the trigger.
- **Section chips** (By date, By venue): shadcn `ToggleGroup` (`type="single"`) in a `ScrollArea`, "Toutes les sections" first. Chip: 44px tall, 8px radius, Surface fill, 1px Border; selected = Gold Leaf fill + leading `Check` glyph (never color alone). Each chip carries the `SectionLabel` glyph (trophy outline for competition, clapperboard for non-competition) before the text. Chips scroll horizontally; overflow is indicated by a 24px fade at the inline-end edge.
- A "Réinitialiser les filtres" Tertiary text button (40px with 44px hit area) appears at the inline-end of the row when any filter is active.
- URL keys: `venue=<venue-slug>`, `section=<section-key>`. Filters apply instantly (client-side, whole festival is already loaded) with `router.replace`.
- Result-count live region (`role="status"`, visually hidden, polite) announces on every change: "{n} séances, {day}".

### A6. By date view (default)

- Day heading (Heading 24, `<h2>`): "Samedi 12 décembre" (AR `DD/MM/YYYY` format per lib/dates in the tile and Meta lines; the long weekday-plus-month heading uses a numeral-safe Arabic locale with Western digits).
- **"Prochaines séances" jump** (secondary pill, Gold Tint text, 1.5px Gold Leaf border, 44px, `ArrowDown` icon) is shown only while the festival is ongoing, the selected day is the current festival day, and a not-yet-started programme exists. It scrolls to that card and moves focus to the card heading (`tabindex="-1"`), and the live region announces "Prochaine séance : {time}, {venue}". It is positioned inline-end of the day heading on mobile in the same row.
- On first load with no `day`/`programme` in the URL during the festival: select the current festival day and scroll to the next programme (not smooth when reduced motion). With a `day` in the URL, do not auto-scroll; with `programme=<key>`, scroll to and outline that card (2px Gold Leaf outline, plus a visually hidden "sélectionné" text).
- Cards are ordered by start time ascending, 16px apart.
- **Current-day grouping (only when the selected day is the current festival day, D-12):** upcoming and in-progress cards first, chronological; below them a **"Déjà projetés ({n})"** `Collapsible` (collapsed by default, 48px trigger with `ChevronDown` that rotates, `aria-expanded`), whose ended cards use the compact variant (header and film titles only, no posters, 16px padding). Any other day (future, past, or whole archive after the festival) lists cards chronologically with no grouping and no "En cours" labels.
- "Next screening" = first programme not yet started (D-12). A card flips to "En cours" at its start and into "Déjà projetés" at its end; recomputed on mount and every 60s without scroll jumps (`overflow-anchor: auto`).

### A7. Programme card (focal component)

Surface `#31203A`, 16px radius, 1px `#4A3556` stroke, no shadow, 16px padding, an `<article>` whose accessible name is its header line. Not itself a link; each film row is.

**Header (two lines):**

- Line 1: time (Body 700, `15h00` FR / `15:00` AR and EN; end time after an en dash when `end` exists: `15h00–16h45`), then a night hint in Label 14/700 `#B0A6B8` ("nuit") when the programme belongs to the previous festival day after midnight; venue name (Body 700, `bdi`) truncated to one line at the inline-end side of the time on wide cards, wrapping below the time at 390px; the status label at the far inline-end (see Status labels).
- Line 2 (chips, 8px gap, wrap): `SectionLabel` (glyph + text), format chip (`videoFormat`, only when every slot shares it, Label 14/700 on Aubergine Deep with 1px Border), "Programme courts" chip for shorts-only programmes (teal dot + teal text on Aubergine Deep, the category cameo), and the compact "✲ Équipe présente" summary when any slot has `teamPresent`.
- Line 3 (Meta 14, `#B0A6B8`), the summary: shorts-only "Programme courts · 5 films · 82 min"; mixed "6 films · 104 min"; single feature "Long métrage · 96 min".

**Body: visible ordered list** (`<ol>`, never hidden behind tabs). Each `ProgrammeFilmRow` is one `<li>` and one link to the film (`/films/<slug>` or `/shorts/<slug>` from the payload `route`), min-height 60px (the thumb height), 8px gap between thumb and text, 8px vertical gap between rows, whole row is the 44px+ target:

- Order numeral in Meta 14 `#B0A6B8` at the inline-start, 16px wide, `aria-hidden` (the `<ol>` carries the order).
- Poster thumb 40 x 60, 8px radius, 2:3; **no poster = reserved diagonal two-tone aubergine stripe**, `alt=""` (the title is adjacent).
- Title (Body 700, up to two lines, `bdi`), then "de {director}" (Meta 14, `#B0A6B8`, `bdi`) and the runtime "12 min" (Meta 14) on the same line separated by "·", then language line when present ("Arabe, st. français", Meta 14), then, if `teamPresent`, the row-level mark: `TeamPresentMark` + "Équipe du film présente" (Label 14/700, white).
- A trailing `ChevronRight` (mirrored in RTL, `rtl:rotate-180`, 16px, `#B0A6B8`) at the inline-end, `aria-hidden`.
- **The feature is listed last and weighted as the main film:** its row uses a 56 x 84 thumb, a 1px `#4A3556` top rule above it (separating it from the shorts), and a Label-role "Long métrage" tag above the title. When there is no short, the single feature row is still the 56 x 84 variant.

**Footer:** "Durée totale : 82 min" (Meta 14) left-aligned (inline-start). No button, no purchase action, no price anywhere on the card.

**Variants:** default (above); compact (ended: no thumbs, no language line, 16px padding, titles listed as plain linked text); skeleton.
**Hover:** card background steps to `#3E2A48` only on pointer devices that hover. **Press** scales to 0.985 on rows only. **Focus:** 2px Gold Leaf outline on the row link, offset 2px.

### A9. `SectionLabel`

Glyph + text always (D-08, D-10). Competition sections: lucide `Trophy` (outline, 16px, stroke 1.75) + the localized section name. Non-competition: lucide `Clapperboard` (outline, 16px) + name. Label 14/700 in `#C9C0D0`, never gold. The glyph is `aria-hidden`; a visually hidden prefix "Section en compétition :" / "Section hors compétition :" precedes the name. Programmes without a section show no label.

### A10. `TeamPresentMark`

An inline SVG asterisk drawn to match the ✲ shape (eight spokes, 16px, `currentColor`, `aria-hidden`), **not** the Unicode character (Inter and IBM Plex Sans Arabic do not carry it; fallback fonts would vary). Always followed by text. Row level: "Équipe du film présente". Header summary: "Équipe présente". White (`#FFFFFF`), not gold.

### A11. By venue view

- Shares the day strip, section chips and venue combobox (selecting a venue narrows to one section).
- One `VenueSection` per venue that has programmes on the selected day, ordered by the number of programmes descending then name **[default]**; venues with none are omitted and summarized by a Meta line at the end: "{n} lieux sans séance ce jour-là".
- Section header: Surface row (12px radius), 16px padding: venue name (Body 700, `<h2>`), address (Meta 14, `#B0A6B8`; city only when the address is empty), and an **"Itinéraire"** secondary pill (Gold Tint text, Gold Leaf border, 44px, `MapPin`, opens `https://www.google.com/maps/search/?api=1&query=<lat>,<lng>` in a new tab; visually hidden "(s'ouvre dans un nouvel onglet)"). **No `geo` = no button**, the address text stays. No embedded Leaflet map.
- Below the header: that day's programme cards for that venue (same `ProgrammeCard`, venue name omitted from line 1 because the section supplies it), time ordered. Same "Déjà projetés" rule on the current day, applied per venue.
- Desktop: sections side by side (2 columns, 3 from 1280px).

### A12. By film view

- One `FilmScreeningsRow` per distinct film, sorted by title with locale collation (`Intl.Collator(locale)`), `content-visibility: auto` with a 120px intrinsic height hint and lazy images (up to about 220 films).
- Row: poster 64 x 96 (80 x 120 from 640px), title (Body 700, `<h2>`, `bdi`, linked to the film page), "de {director} · {runtime}" (Meta 14), `SectionLabel` of the film's competition section when it has one (D-10), and the original-title line when the original locale differs from the display locale (Meta 14).
- Below: screenings grouped **by day** (sub-heading Label 14/700, "Samedi 12 décembre"), then **by venue** within the day. Each screening is a **showtime tile**: min 44px tall, Surface, 8px radius, time (Body 700), venue (Body 400, `bdi`), `SectionLabel` text, and `TeamPresentMark` + "Équipe présente" when set; status label when cancelled/postponed. The tile carries **no purchase action**: it is a link that opens the programme in the By-date view (`?view=date&day=<day>&programme=<key>`, scroll + outline), with accessible name "Ouvrir la séance de 15h00 à {venue}". A short screened in two programmes lists both tiles, each also showing "Programme courts · {n} films" as its programme line.
- Text search `Input` (44px, `Search` icon, `type="search"`, `autocomplete="off"`, label visible to AT) filters by title, original title and director, debounced 300ms; URL key `q`. Diacritic- and case-insensitive. **[default]** (addition for 165 to 220 films; consistent with the "under a minute" outcome).
- `?film=<documentId>` scrolls to and focuses that row's heading.

### A13. URL contract

`/[locale]/festivals/[slug]?view=date|venue|film&day=YYYY-MM-DD&venue=<slug>&section=<key>&q=<text>&programme=<key>&film=<documentId>`. `view` defaults to `date`; `day` defaults per rules above (current festival day during the festival, day 1 before it, day 1 of the archive after it; absent = "Tous" in By film). Unknown or out-of-range `day`, `venue`, `section` values are ignored and replaced silently. The page route is statically cacheable; state is read in a client island (`useSearchParams` inside `Suspense`). Shared links open the same view.

### A14. Time and day rules the UI must show

- All times are Africa/Tunis whatever the device zone (D-13). Format: FR `HH[h]mm` (`15h00`), AR and EN `HH:mm` with `hourCycle: h23` and Latin digits (`15:00`); never `3:00 م`.
- A festival day is 05:00 to 04:59 (D-11): a 00:30 programme sits under the previous evening's tile with the real time and the "nuit" hint.
- "Now" is computed after mount and every 60s, never during render (avoids hydration mismatch). Server HTML renders no time-dependent labels.

## Part D — Accessibility and RTL (public)

- WCAG 2.1 AA, **axe-core clean at 390px in fr, ar and en** (structural rules in Vitest/jsdom plus a recorded manual contrast pass; jsdom cannot compute contrast).
- Landmarks: one `<main>`, `<nav>` for the day strip group labelled "Jours du festival", `<h1>` festival name, `<h2>` per day/venue/film, `<article>` per programme card, `<ol>` per film list.
- Targets 44px minimum with 8px spacing; focus visible everywhere (2px Gold Leaf, 2px offset); logical tab order equals visual order in both directions.
- Status is never color alone: every status and selection has an icon or glyph and text.
- Live regions: result count and next-screening announcements are `role="status"`, polite; no announcement on the 60s recompute.
- Zoom 200% without horizontal page scroll (only the day strip and chip row scroll, each focusable and labelled).
- `prefers-reduced-motion`: instant scroll, no pulse, no card lift, no skeleton animation.
- **RTL:** `dir="rtl"` on `<html>` for `ar`; logical properties only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`); the day strip, view tabs and arrow keys mirror; `ChevronRight`/`ArrowRight` get `rtl:rotate-180`; `Trophy`, `Clapperboard`, `MapPin`, `TeamPresentMark` do not mirror; the order of the film list is reading order (first film at the top in both directions); times, counts and dates use Western digits; mixed runs (an Arabic title beside `VOST` or a Latin venue name, `15:00`) are isolated with `<bdi>`.
- Locale time formats exactly as in A14; dates via `lib/dates.ts` with `toNumeralSafeLocale` (never a raw `ar` locale); Arabic dates `DD/MM/YYYY` in numeric contexts.

## Part G — Admin: Event-groups page (Strapi Design System v2)

Plugin: `apps/strapi/src/plugins/events-manager/admin/`. Visual authority: `apps/strapi/DESIGN.md` and `.claude/skills/strapi-design-system/`. Use the v2 compound APIs (`Field.Root`, `Modal.Root`), not the Claude Design kit's prototyping props. One primary (`default`) button per view group. `IconButton` always has a `label` and a `Tooltip`. Sentence case, imperative, no emoji, `@strapi/icons` only. Spacing and padding follow `pages/Works` (`Layouts.Header`, `Layouts.Content`, `PAGE_GUTTER`).

**Routes and navigation:** `event-groups` and `event-groups/new` and `event-groups/:documentId` in `pages/App.tsx`; a `SideNav` `NAV_ITEMS` entry "Event groups" placed after Planning. **RBAC (D-18):** the nav item and routes require `plugin::events-manager.festivals.manage`; without it the entry is hidden and a direct URL renders `Page.NoPermissions`. Super Admin has it; Editor is granted it in Settings > Roles.

### G1. List screen

- `Layouts.Header`: title "Event groups" (`alpha`), subtitle "Festivals, seasons and series that group events.", primary `Button` "Create event group" (start icon `Plus`).
- Toolbar: `Searchbar` (title) and `SingleSelect` "Type" (All, Festival, Season, Series, Retrospective, Special).
- `Table`: Title (link to detail), Type (`Badge`, non-semantic), Dates, Events (count), Publication (`Status`: Published success, Draft neutral, Modified warning), actions column with `IconButton` "Edit event group" (`Pencil`).
- Empty: `EmptyStateLayout` "No event groups yet." with "Create event group". Loading: `Page.Loading`. Error: `Page.Error` with retry.

### G2. Detail screen

`Layouts.Header`: back `Link` "Event groups", title = group title (`alpha`), `Status` for publication, secondary `Button` "Save event group", primary `Button` "Publish event group" (Draft & Publish convention). Festival-specific tabs appear only when `type === "festival"`. `Tabs`: **Info**, **Sections**, **Programme**, **Import** (non-festival groups show Info only).

**Info tab:** `LocaleTabs` (fr, ar, en; reuse WorkForm's) for localized Title and Short title; Slug (`TextInput`, read-only once published, hint "The slug is the festival's address and its import key."); Type (`SingleSelect`); Start date and End date (`DatePicker`); Timezone read-only "Africa/Tunis"; Poster and Hero (`MediaInput`). Validation via React Hook Form + Zod; errors via `Field.Error` with specific copy ("Add a French title before publishing.").

**Sections tab:** `Table` of festival sections: Name (fr shown, `Badge` per missing translation), Key, Kind (`Status`-less `Badge`: Competition / Non-competition), Order, actions (`IconButton` "Move section up", "Move section down", "Edit section", "Delete section"). No drag and drop (keyboard-accessible arrows). Primary `Button` "Add section" opens `Modal.Root`: Name per locale (`LocaleTabs`), Key (`TextInput`, unique per festival), Kind (`SingleSelect`), Order (`NumberInput` using `onValueChange`); footer "Save section" (primary) and "Discard changes" (tertiary). Delete uses `Dialog` with buttons "Delete section" (confirm) and "Keep section" (dismiss); if programmes use the section the delete is blocked with the message below.

**Programme tab:** filters row: Day (`SingleSelect`, the festival days with programme counts), Venue (`Combobox`), Section (`SingleSelect`), Status (`SingleSelect`), `Searchbar` (film title). `Table` of programmes for the selected day: Time (in Africa/Tunis), Venue, Section, Films (ordered titles; count `Badge` if more than 3), Team present (`Badge` with the text "Team present" when any film is flagged; no Unicode-character icons in the admin), Status (`Status`: Scheduled neutral, Cancelled danger, Postponed warning, Rescheduled warning), actions `IconButton` "Edit programme". **Edit programme `Modal.Root`** (reuses `SubEventModal` request builders): Status (`SingleSelect`), Start and End (`DateTimePicker`, Tunis time shown), New start time (`DateTimePicker`, only when Rescheduled), Venue (`Combobox`), Section (`SingleSelect`), Films: an ordered list with `IconButton` "Move film up/down" and a `Checkbox` "Film team present" per row, read-only film title and runtime. Footer: `Button` variant tertiary "Discard changes" (closes the modal without saving; deliberately not "Cancel", which is reserved for the cancel-programme dialog), primary `Button` "Save and publish programme". Saving a programme saves **and publishes atomically** and fires revalidation; success `useNotification` toast "Programme published. The public page updates within about a minute." Changing status to Cancelled or Postponed first opens a `Dialog` confirmation whose buttons are "Cancel this programme" / "Postpone this programme" (confirm) and "Keep programme scheduled" (dismiss).

**Import tab** (four numbered `Box` cards with `beta` headings, top to bottom, later steps disabled until the previous is done):

1. **Choose the file:** `Button` variant secondary "Choose JSON file" (hidden native `<input type="file" accept="application/json">` with a visible `Field.Label`; this is the one allowed native control because the DS has no file input), file name and size shown, `Field.Hint` "Use the programme file drafted for this festival."
2. **Check the file** (dry run, read-only): `Alert` summary (success "No errors", warning "N warnings", danger "N errors block the import") and a `Table` of issues: Severity (`Status`), Code (`Badge`), Row key, Message, Action. Codes (not prose) come from the server: `SCHEMA_INVALID`, `DUPLICATE_PROGRAMME_KEY`, `UNKNOWN_VENUE`, `UNKNOWN_SECTION`, `FILM_NOT_IMPORTED`, `TMDB_ID_UNRESOLVED`, `FILM_BELOW_MINIMUM`, `OUTSIDE_FESTIVAL_RANGE`, `STATUS_INVALID`, and warnings `VENUE_OVERLAP`, `EXISTING_PROGRAMME_SKIPPED`, `EXISTING_DIFFERS`. Messages are looked up from the plugin translations by code.
3. **Prepare films:** list of distinct TMDB ids with per-film state (`Status`: Ready, Pending, Failed), `ProgressBar` ("38 of 214 films prepared"), `Button` "Prepare films" (batches of about 20, resumable; label becomes "Resume preparing films" after a stop). A failed or unresolved row offers the **"Not on TMDB?" path**: an `Alert` (info) "Add the film on themoviedb.org, then paste its id here." with an external `Link` "Open themoviedb.org" and a `Modal.Root` "Link a TMDB id" (`NumberInput` TMDB id; footer "Link film" primary and "Close without linking" tertiary). Rows below the D-04 minimum show `FILM_BELOW_MINIMUM` with the same path.
4. **Import programme:** primary `Button` "Import programme" (disabled while any error exists), opens a `Dialog` (confirm "Import {n} programmes", dismiss "Keep reviewing"): "Import {n} programmes?" with body "Existing programmes are skipped and reported, never overwritten. Everything is published when the import finishes." Result `Alert` with counts (created, skipped, warnings).

**WorkForm change (D-07):** in each locale tab a `Switch` labelled "Original language" with `Field.Hint` "Marks this language as the original. Setting it unmarks {other locale}."; exactly one locale can be on; the tab of the original locale shows a `Badge` "Original". The old "Original title" field is removed.

**Admin states:** loading `Page.Loading`; error `Page.Error` with retry; empty tables use `EmptyStateLayout` with one action; success toasts are short and specific ("Event group saved", "Event group published"); errors are specific ("This key is already used in this festival."); long operations (prepare films) announce progress via `LiveRegions`/`ProgressBar` labels.
