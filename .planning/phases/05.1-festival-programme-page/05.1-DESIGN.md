# Festival programme page — visual design

`05.1-UI-SPEC.md` remains the detailed contract (tokens, programme card, status labels,
section label, team-present mark, URL contract, time rules, accessibility). This file
records the owner's layout choice of 2026-11-09 and every place it changes that contract.
Where the two disagree, **this file wins**.

## Layout decision

Three directions were drawn on the canvas linked above: A "Affiche" (stacked cards, the
spec as written), B "Fil horaire" (time rail) and C "Grille" (venue lanes × time).

| Width                        | Layout              | Mockup artboards                                                    |
| ---------------------------- | ------------------- | ------------------------------------------------------------------- |
| Below 1024px (phone, tablet) | **B · Fil horaire** | "B · Fil horaire — Par date (FR)", "(AR, RTL)", "tablette 768 (FR)" |
| 1024px and up                | **C · Grille**      | "C · Grille — Desktop 1280 (FR)"                                    |

Direction A is not built. Its "Par film" artboard stays the reference for the By-film
view on both widths (see below), because B and C only redraw the By-date view.

Rationale: on a phone between screenings the question is "what's on now and next", which
the rail answers at the scroll position the page opens on, with every film still listed.
On desktop people plan a day; the grid shows clashes and gaps across venues at a glance,
and the side panel restores the full film list that the grid blocks abbreviate.

## Views per width

| View (URL `view=`) | Below 1024px                                 | 1024px and up                                          |
| ------------------ | -------------------------------------------- | ------------------------------------------------------ |
| `date` (default)   | Time rail (B)                                | Venue-lane grid + detail panel (C)                     |
| `venue`            | Spec A11 sections, rail-card variant         | Spec A11 sections side by side (2 cols, 3 from 1280px) |
| `film`             | Spec A12 (artboard "A · Affiche — Par film") | Spec A12, single column max 720px                      |

The tab label stays **"Par date" / "حسب التاريخ" / "By date"** on both widths. The desktop
mockup's "Grille" label is superseded: one view, two renderings, one URL.

## B · Fil horaire (below 1024px)

Supersedes spec A1 items 2–4 and A6 for this width.

- **Festival header, compact:** 40 × 60 poster (8px radius, stripe if missing), name at
  22/700 (`<h1>`, balanced, line-height 1.25; 1.35 in Arabic), so it stays larger than
  the 20px day heading; meta "{start} – {end} · {n} lieux", share disc 44px.
- **Sticky stack is the day strip only** (64px tiles, as spec A4). The view tabs leave the
  top of the page.
- **View switch = floating segmented control** above the bottom nav: three equal segments
  (Date · Lieu · Film), 44px tall, inside a 4px-padded pill on Aubergine Deep with a 1px
  Border stroke, no shadow. Selected segment: Gold Leaf fill, Gold Ink label, leading
  check glyph. Placed at `bottom: 64px + 14px + env(safe-area-inset-bottom)`, inline
  inset 24px. Page bottom padding grows by 72px so the last card clears it. Hidden while
  the on-screen keyboard is open (By-film search). Semantics: views change the URL and
  there is no tab panel, so the control is `<nav aria-label="Vue du programme">` with one
  link per view and `aria-current="page"` on the active one (not a `tablist`).
- **Filter row** unchanged (venue combobox, section chips), scrolls away.
- **Day line:** day heading (Heading 20/700, `<h2>`) with the day's count at inline-end
  ("18 séances", Meta 14).
- **Rail:** a 2px Border line at inline-start + 79px. Each **slot** is a two-column grid:
  52px time column (Body 16/700, text-align end, tabular numerals) and the programmes.
  Programmes that start at the same minute share one slot, stacked 10px apart, and the
  time column adds "{n} séances" under the time. A 12px node sits on the line at each
  slot: hollow (Muted stroke) for upcoming, solid success green for in progress.
  After-midnight programmes show the real time with "nuit" under it (spec A14).
- **"Maintenant" line:** a 2px white rule across the content column with a 10px white
  dot on the rail and the label "Maintenant / {time}" in the time column (Label 12/700).
  Placed after the last programme that has started and before the first that has not.
  White, not gold (it marks time, not an action) and not green (it is not a status).
  Only on the current festival day.
- **Past programmes are not shown** (see "Past content" below). On the current day the
  rail opens with the programmes in progress, then the "Maintenant" line, then the next
  ones. There is no fold and no "Déjà projetés" group; spec A6's collapsible is dropped.
- **"Prochaines séances" jump** (spec A6) is dropped on this width: the page opens
  scrolled to the "Maintenant" line, which is the same target.
- **Rail card** (variant of spec A7): Surface, 12px radius, 1px Border, 12px padding.
  Header: venue (Body 15/700, `bdi`), "jusqu'à {end}" (Meta 13), status label at
  inline-end. Tag row: section label (glyph + text, 12px), then the programme summary
  ("Programme courts · 5 films · 82 min" in courts teal with its dot; "2 films · 104 min"
  or "Long métrage · 98 min" in Meta). The summary carries the total runtime, so the card
  has no footer. Film rows: 32 × 48 thumb (the feature film 40 × 60, listed last), title
  14/700 two lines max, "de {director} · {runtime}" 12px, the team-present mark when set,
  trailing chevron. Rows are 56px minimum and separated by a Hairline rule. Every film of
  the programme is listed; nothing is hidden.

### Tablet (640px to 1023px)

Same rail, same components, same order as the phone; only the measures change. Artboard:
"B · Fil horaire — tablette 768 (FR)".

- **Margins:** 24px inline (apps/client DESIGN.md tablet gutter), replacing the phone's 16px.
- **Card column capped at 560px.** The slot grid is a 68px time column + 24px gap + the
  programmes, capped at 652px in total and aligned to inline-start. The leftover width
  (about 90px at 768px) stays empty at inline-end. Cards never stretch to the full width.
- **Same-time programmes stay stacked**, not side by side. A slot holds 1 to 6 programmes
  of 1 to 8 films each, so two columns would leave ragged, half-empty rows and break the
  single top-to-bottom scan that the "Maintenant" line depends on. One
  card component serves phone and tablet, and 560px keeps titles at a readable length.
- **Time column 68px** (phone: 52px), so "2 séances", "nuit" and "Maintenant / {time}"
  fit on one line. The rail line moves with it, and the node and the "Maintenant" dot are
  centred on that line.
- **Day strip:** every remaining festival day visible at once (72px tiles; eight before
  JCC opens); it scrolls sideways only when the days don't fit.
- **Filter row:** venue combobox and section chips on one line; it scrolls sideways
  when the chips overflow, as on the phone.
- **Floating view switch:** centred, 400px wide, instead of the phone's 24px inline
  insets; same vertical placement above the bottom nav.
- **Bottom nav** kept, as on the phone. The desktop sidebar and grid start at 1024px.

## C · Grille (1024px and up)

Supersedes spec A2's By-date column for this width; the sidebar is kept.

- **Sidebar, 240px, sticky:** 96 × 144 poster, name (Heading 22/700), meta, "Partager le
  programme" secondary pill, vertical tablist (selected: Surface fill, 3px Gold Leaf
  inline-start rule, 8px end radius), "Sections" label and wrapping section chips. The
  venue combobox is not shown in the By-date grid (lanes are the venues); it stays in the
  By-venue view.
- **Main column:** day strip (all remaining days visible, 64px tiles), then a split: grid
  at inline-start, detail panel at inline-end, 24px apart.
- **Grid:** 1px Border frame, 12px radius, clipped. Time column 52px with hour labels
  (12/700 Muted); hour rules every 72px in Hairline; scale **1.2px per minute**. The
  window runs from the hour before the day's first start to the hour after its last end,
  inside the 05:00–04:59 festival day. On the current day, finished blocks are removed
  and the window starts at the hour of the earliest programme still shown (in progress
  or upcoming).
- **Lanes:** 136px each, venue name header 44px (13/700, `bdi`). Order: number of
  programmes that day, descending, then name (spec default). Up to four lanes are visible
  next to the panel; more scroll horizontally inside the grid with a 32px fade at the
  inline-end edge. The time column stays put while lanes scroll.
- **Blocks:** absolutely placed at start time, height = duration × 1.2 − 4px, 4px inline
  inset, 8px radius, Surface, 1px Border. Content, clipped to the block: start time
  (13/700) with the team-present mark at inline-end when any film has it; status label
  (in progress, cancelled, postponed); section in short form with its glyph ("Compét.
  longs"); courts programmes show "Courts · {n} films" in teal; then either the single
  film (title 13/700, "{initial}. {surname} · {runtime}") or the ordered titles (12px,
  one line each, ellipsis), ending in "+ {n}" when they do not fit.
  Cancelled: Aubergine Deep fill, dashed Border, struck time, icon + "Annulé".
  In progress: success-tinted border plus the "En cours" label.
- **"Now" line:** 2px white across all lanes with a white time chip ("15h12") in the
  time column. Current festival day only.
- **Selected block:** 2px Gold Leaf outline at 1px offset and Surface Raised fill, plus
  `aria-current="true"`. Selection is the gold use on this surface.
- **Detail panel:** Surface, 16px radius, 1px Border, 20px padding, the full programme
  card of spec A7 (thumbs 40 × 60, feature 56 × 84 listed last, team marks, total
  runtime footer) with a header "{start}–{end}" (Heading 20/700) + venue, and a 44px
  close disc ("Fermer le détail de la séance"). Sticky under the app header while the
  grid scrolls. With nothing selected it shows the next programme to start (current day)
  or the first programme of the day, so the panel is never empty.

## Past content (owner directive, 2026-11-09)

During the festival the page shows only what is still ahead. A programme is past when it
ends (`endDateTime`, otherwise start + total runtime), and it then leaves every view. A
programme in progress is not past: it stays, with "En cours". Supersedes the "Déjà
projetés" rules in spec A6, A11 and E1 and in the design brief.

| Where                         | During the festival                                                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Day strip (all views)         | Starts at today ("Auj."); past days are not shown. By-film's "Tous les jours" means all remaining days.                                              |
| By date: rail / grid          | Finished programmes removed; no fold. The grid window starts at the earliest programme still shown.                                                  |
| By venue                      | Finished programmes removed from each venue section; a venue with nothing left that day drops out.                                                   |
| By film                       | Past showtime tiles removed, then empty day sub-headings; a film with no showtime left drops out of the list and the count.                          |
| `/films/[slug]` "Au festival" | Upcoming and in-progress screenings only. When none remain, the rows are replaced by one line, "Plus de séance prévue à ce festival", with no times. |
| Deep links                    | `day=` in the past opens today; a `programme=` that has ended opens today with nothing selected.                                                     |
| Empty day                     | Only a remaining day can be empty; its next-day action points forward.                                                                               |

**Before the festival:** unchanged; every day is shown, from day 1.
**After the festival:** the full read-only archive stays (every day, every screening, no
"Auj.", no "En cours"). This is the one exception.

## Shared rules (both widths)

- Tokens, status labels, section label, team-present mark, stripe artwork, focus ring and
  bdi isolation exactly as in `apps/client/DESIGN.md` and spec A7–A10.
- Gold appears only on: the selected day tile, the selected view segment or tab, the
  selected section chip, the selected grid block, and pill CTAs. The "now" marker is white.
- No purchase action, price, carousel or hidden film list anywhere.
- RTL: both layouts are built with logical properties. In Arabic the rail sits on the
  right with times to its right edge; grid lanes run right to left with the time column
  at the right; the detail panel moves to the left. Chevrons mirror; glyphs do not.
- Arabic text uses Noto Sans Arabic (the face loaded by `src/lib/fonts.ts`), not IBM Plex
  Sans Arabic as the spec's Design System table says; owner decision pending on switching faces.
