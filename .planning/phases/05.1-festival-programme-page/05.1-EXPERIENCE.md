# Festival programme page — experience

Flows, states and copy for the layouts chosen in `05.1-DESIGN.md`. Everything not listed
here follows `05.1-UI-SPEC.md` (Parts A–D and the copywriting contract).

The owner approved the public-site mockups on 2026-11-09. The Event-groups admin
mockups (`mockups_outstanding`) are not drawn yet: `admin_mockup_status` stays `pending`
and no admin UI plan executes until they are drawn and approved. The build gate only
reads `mockup_status`, so this hold is enforced by plan review, not by the gate.

### Build notes from the 2026-11-09 accessibility audit

The mockups were approved as drawn. The build applies these corrections:

- Grid blocks (≥1024px) carry no `aria-label` that replaces their content; visible text
  plus an sr-only section prefix names them, as the rail cards already do.
- Day tiles and section chips expose `aria-pressed` (true/false) on every item;
  `aria-current="date"` marks today only. The venue picker sets `aria-haspopup`/`aria-expanded`.
- The load error uses `role="alert"`; result counts for search and filters sit in a polite live region.
- Focus rings keep a transparent `outline` fallback so they survive forced-colours mode.
- Field and chip borders reach 3:1 against their background.
- Day strip and filter row scroll inline with scroll-snap and an edge fade; the selected
  day scrolls into view on load. The floating view switch adds `env(safe-area-inset-bottom)`.
- The grid at 1024–1279px is laid out in `05.1-DESIGN.md` before the grid is built.
- Reduced motion: the jump to "Maintenant" is instant; no global duration kill.
- The date view uses one name in all three languages on phone and desktop.

## Core flows

### "What's on now?" (phone, during the festival)

1. Visitor opens `/fr/festivals/jcc-2026` from a social link. No `day` in the URL.
2. The page selects today's tile ("Auj.") and, after mount, scrolls to the
   "Maintenant" line (instant under reduced motion). Server HTML renders no
   time-dependent labels; "now", "En cours" and which programmes are past are computed
   client-side and refreshed every 60s without moving the scroll position.
3. The day strip starts at today. In-progress programmes open the rail with "En cours",
   then the line, then the next ones. Finished programmes are not shown at all.
4. Tapping a film row opens `/films/<slug>` or `/shorts/<slug>`. Back returns to the
   same scroll position.

### "What's on at this venue?" (phone)

Floating switch → "Lieu". View changes use `router.push` (Back steps through them).
Sections per venue as spec A11, with rail-style cards.

### "Where and when does this film play?" (both widths)

Switch → "Film". Search, rows and showtime tiles as spec A12, remaining showtimes only
(a film with none left is not listed). A tile opens
`?view=date&day=<day>&programme=<key>`: on a phone the rail scrolls to that programme
and outlines it; on desktop the grid scrolls its block into view, selects it, and the
detail panel shows it.

### Planning a day (desktop)

1. The grid shows the selected day; the panel shows the next programme to start
   (current day) or the day's first programme.
2. Clicking or pressing Enter on a block selects it, updates `programme=` with
   `router.replace`, fills the panel and moves focus to the panel heading.
3. The close disc or Escape clears the selection (panel falls back to the default
   programme) and returns focus to the block.
4. A shared link with `programme=` opens with that block selected. If that programme
   has ended, or `day=` is a past day, the page opens on today with nothing selected.

## Interaction details

- **A programme ends while the page is open:** on the next 60s refresh its card (rail),
  block (grid) or showtime tile (By-film) is removed. Removal never moves what the
  visitor is reading (scroll anchoring) and is not announced. If the selected grid block
  ends, the panel falls back to the next programme to start. At the end of the festival
  day (04:59), the strip drops the finished day and today moves to the next one.
- **Floating switch:** stays visible while scrolling; hidden when the keyboard is open.
  It never covers the last card (bottom padding).
- **Grid keyboard order:** blocks are links, grouped per lane (lane header is an `<h3>`
  venue name), time-ordered inside the lane. Tab moves lane by lane in reading
  direction. Horizontal lane scroll follows focus.
- **Grid semantics:** each lane is a list of programmes; each block's accessible name
  is "{time}, {venue}, {section}, {n} films" plus the status when set.
- **Filters:** section chips (and the venue combobox on the rail) apply instantly.
  On the grid, filtered-out blocks are removed and lanes left empty collapse; the
  live region announces "{n} séances, {day}".
- **Breakpoint change** (rotate, resize across 1024px): view, day, filters and
  `programme` are kept; only the rendering changes.

## States (deltas over spec Part B)

| State                                         | Rail (below 1024px)                                                                                              | Grid (1024px and up)                                                              |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Loading                                       | Compact header skeleton, one tile per remaining day, the floating switch, 4 rail-card skeletons on the rail line | Sidebar skeleton, day strip, 4 lane headers and 6 block skeletons, panel skeleton |
| Empty day (a remaining day with no programme) | Rail replaced by the empty state (spec copy, action to the next day with screenings); switch stays               | Grid and panel replaced by the empty state                                        |
| Nothing left today (last programme ended)     | Empty state "Plus de séance aujourd'hui" with an action to the next day                                          | Same, in place of grid and panel                                                  |
| Empty after filters                           | Empty state with "Réinitialiser les filtres"                                                                     | Same, in place of grid and panel                                                  |
| Before the festival                           | Banner; every day from day 1; no "Maintenant" line                                                               | Banner; no now line; panel shows day 1's first programme                          |
| After the festival                            | Banner; full archive of every day and screening; no line, no "En cours"                                          | Banner; archive grid                                                              |
| Not the current day (a later day)             | No line, all programmes listed                                                                                   | No now line                                                                       |
| One venue only                                | Rail as usual                                                                                                    | Single lane plus panel; the grid does not stretch the lane                        |
| More than 4 venues                            | n/a                                                                                                              | Lanes scroll horizontally inside the grid; fade at the inline-end edge            |
