<objective>
ImageKit uploads mirror the Strapi Media Library folder tree under an environment root
(D-01): `{IMAGEKIT_FOLDER}/{env}/{slugified Media Library folder names}/{hash}{ext}`, with
files outside any folder in `{root}/{env}/unsorted/`. A local workspace upload provider
replaces the npm one (D-02). Thumbnails and responsive formats follow their parent image
(D-03). The short-film seed files posters and backdrops into Media Library folders (D-07).

Purpose: ImageKit storage stays browsable and separated per environment, instead of every
file of every environment landing in one flat `tiween` folder.

Output: `packages/strapi-provider-upload-imagekit/` (provider + node:test suite), Strapi
config and dependency switch, folder-aware seed media helper, updated tests and env docs.

Scope boundary: placement happens at upload and replace time. Moving or renaming a Media
Library folder afterwards does not move files already stored in ImageKit (recorded in
`261024-iy3-EXPERIENCE.md`; report it in the SUMMARY).
</objective>
