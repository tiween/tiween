# Design Tokens

This page documents the design tokens used throughout the Tiween design system. These tokens are defined in `src/styles/theme.css` using CSS custom properties with Tailwind CSS v4.

## Color System

The Tiween color system uses the **OKLch** color space for perceptually uniform colors that look consistent across different hues.

### Brand Colors

| Token | Value | Usage |
|-------|-------|-------|
| `--color-primary` | `oklch(92.8% 0.2 103.76)` | Tiween Yellow #F8EB06 |
| `--color-background` | `oklch(18% 0.03 170)` | Tiween Green #032523 |
| `--color-surface` | `oklch(22% 0.03 170)` | Elevated surface |

### Semantic Colors

| Token | Light Mode | Dark Mode | Usage |
|-------|------------|-----------|-------|
| `foreground` | Gray 950 | Gray 50 | Primary text |
| `muted` | Gray 100 | Gray 800 | Subdued backgrounds |
| `muted-foreground` | Gray 500 | Gray 400 | Secondary text |
| `accent` | Gray 100 | Gray 800 | Interactive highlights |
| `destructive` | Red | Red | Error states, delete actions |

### Usage in Tailwind

```tsx
// Background colors
<div className="bg-background" />
<div className="bg-surface" />
<div className="bg-primary" />

// Text colors
<span className="text-foreground" />
<span className="text-muted-foreground" />
<span className="text-primary" />
```

## Typography Scale

| Class | Size | Line Height | Usage |
|-------|------|-------------|-------|
| `text-xs` | 12px | 16px | Badges, captions |
| `text-sm` | 14px | 20px | Secondary text, labels |
| `text-base` | 16px | 24px | Body text |
| `text-lg` | 18px | 28px | Subheadings |
| `text-xl` | 20px | 28px | Section titles |
| `text-2xl` | 24px | 32px | Page titles |
| `text-3xl` | 30px | 36px | Hero titles |

### Font Families

| Token | Value | Usage |
|-------|-------|-------|
| `--font-sans` | Inter, system-ui | Body text |
| `--font-display` | Lalezar, cursive | Decorative headings |
| `--font-arabic` | Noto Sans Arabic | Arabic content (RTL) |

```tsx
// Usage
<h1 className="font-display">Decorative Heading</h1>
<p className="font-sans">Body text</p>
<p className="font-arabic" dir="rtl">النص العربي</p>
```

## Animation

### Transitions

| Token | Duration | Usage |
|-------|----------|-------|
| `transition-colors` | 150ms | Color changes |
| `transition-all` | 150ms | General transitions |
| `duration-200` | 200ms | Slightly slower |
| `duration-300` | 300ms | Modal animations |

### Keyframes

| Animation | Description |
|-----------|-------------|
| `spin` | Continuous rotation (loading spinners) |
| `ping` | Pulse outward (notifications) |
| `pulse` | Opacity fade (skeleton loading) |
| `bounce` | Bounce effect (attention) |

### Mobile-First Approach

```tsx
// Mobile base, then responsive overrides

  <h1 className="text-2xl md:text-3xl lg:text-4xl">
    Responsive Heading
  </h1>
</div>
```
